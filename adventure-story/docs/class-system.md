# 冒險物語 — 職業系統設計 v1

## 決定事項
- 轉職時機：**Lv5 在村莊冒險者公會轉職**（劇情事件），Lv15 二轉留到第二章
- 第一批職業：**劍士／法師／遊俠**
- 全部沿用現有 16 格戰鬥動作，不重畫人物；外觀差異靠 v7 裝備系統（材質＋武器圖層）

## 1. 職業流程
| 階段 | 職業 | 取得方式 |
|---|---|---|
| Lv1–4 | 見習冒險者 | 預設 |
| Lv5 | 劍士／法師／遊俠 | 公會 NPC 對話選擇，選前可看說明與試用技能 |
| Lv15 | 二轉（未實作） | 第二章 |

- 見習期技能：強斬（Lv1）、治癒術（Lv3）
- 轉職時保留已學技能；之後依職業學新技能
- 舊存檔：`H.cls` 不存在 → 設為 `novice`；若已 ≥Lv5，回村時公會觸發補選

## 2. 職業數值
現有公式：`mhp=20+vit*4+lv*3`、`mmp=8+int*2+lv`、`atk=str*2+武器`、`mag=int*2+武器魔力`、`def=vit+防具`、`spd=agi`

| 職業 | 每升 1 級自動加成 | 公式修正 | 被動 |
|---|---|---|---|
| 見習 | 無 | 無 | 無 |
| 劍士 | STR+1、VIT+1 | HP +10% | **追擊**：普攻 15% 機率再打一次（60% 傷害） |
| 法師 | INT+2 | MP +20%、受物理傷害 +10% | **弱點專精**：弱點倍率 ×1.5 → ×2 |
| 遊俠 | AGI+2 | 暴擊率 = 5% + AGI×0.8% | **先制**：戰鬥開始 30% 機率先手；逃跑必定成功 |

- 自由配點 `H.pts` 照舊（每級 3 點），職業加成是額外的
- 轉職當下一次性補發：(目前等級 − 4) × 每級加成

## 4. 裝備限制
`GEAR` 新增欄位 `wt`（武器類型）與 `cls`（可裝職業）：

| 類型 | 劍士 | 法師 | 遊俠 | 現有武器 |
|---|---|---|---|---|
| 劍 sword | ✓ | — | ✓ | 木劍、鐵劍、鋼劍、銀紋劍 |
| 杖 rod | — | ✓ | — | 魔紋短劍 → 改為「魔紋杖」 |
| 細劍／短劍 dagger | ✓ | ✓ | ✓ | 精靈細劍 |
| 重甲 | ✓ | — | — | 鎖甲 |
| 輕甲 | ✓ | — | ✓ | 皮甲 |
| 布／長袍 | ✓ | ✓ | ✓ | 布衣、（新）見習長袍 |

- 見習期可裝全部
- 轉職時身上裝備不符 → 自動卸到背包，改裝職業初始裝備
- 職業初始裝備：劍士＝鐵劍＋皮甲、法師＝魔紋杖＋見習長袍、遊俠＝精靈細劍改為「獵人短劍」＋皮甲
